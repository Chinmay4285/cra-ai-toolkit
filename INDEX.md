## WORKFLOW DECISION TREES

### "I need to learn something"

```
↓ What learning style do you prefer?
├─ Factual explanation → teach-me.md
├─ Story/narrative → explain-like-a-story.md
├─ Visual/diagram → teach-with-diagram.md
├─ Simple version → explain-simply.md
└─ Compare to something → compare-concepts.md
```

### "I need to test myself"

```
↓ What format do you prefer?
├─ Multiple choice → multiple-choice-quiz.md
├─ Realistic scenarios → scenario-quiz.md
├─ Flashcards → quizlet-generator.md or flashcards.md
├─ Rapid fire facts → rapid-review.md
└─ Adaptive tutoring → personal-cra-tutor.md
```

### "I need to analyze documents"

```
↓ What's your goal?
├─ Understand one protocol → protocol-analyzer.md
├─ Summarize it → document-summary.md
├─ Find problems → red-flags.md
├─ Compare multiple docs → inconsistency-detector.md
├─ Find gaps → missing-information.md
└─ Extract terminology → terminology-extractor.md
```

### "I'm preparing for a monitoring visit"

```
↓ When is your visit?
├─ 1-2 weeks away → monitoring-visit-prep.md
├─ Right before → rapid-review.md (facts only)
├─ During visit → monitoring-visit-prep.md (checklist)
├─ Just finished → monitoring-visit-followup.md
└─ Need to practice → mock-monitoring-visit.md
```

### "I found a problem"

```
↓ What kind of problem?
├─ Data quality issue → site-issue-analysis.md
├─ Potential deviation → protocol-deviation-analysis.md
├─ Safety concern → protocol-deviation-analysis.md (escalate)
├─ Multiple problems → issue-triage.md
└─ Need root cause → root-cause-analysis.md
```

### "I need to improve my knowledge"

```
↓ How much time do you have?
├─ 30 minutes → rapid-review.md + brief quiz
├─ 1-2 hours → build-study-knowledge.md (select phases)
├─ Full day → build-study-knowledge.md (all phases)
├─ Ongoing → personal-cra-tutor.md
└─ Before monitoring → monitor-visit-prep.md
```
